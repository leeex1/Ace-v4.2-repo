# Glossary

## Architecture
- **HNMoE** — Hierarchical Networked Mixture-of-Experts. The core architecture using 33 specialized experts with a 300M complexity router.
- **Council (C1-C33)** — 33 cognitive personas mapped to neuroanatomical structures, each governing a domain of expertise.
- **EGGROLL** — Evolution Guided GeneRal Optimisation via Low-rank Learning. Framework for the 9B virtual micro-agent swarm.
- **BitNet / 1.58-bit** — Ternary quantization scheme (-1, 0, +1) using Straight-Through Estimator training.
- **CCRL** — Council-Calibrated Reinforcement Learning. Multi-objective RL with council consensus policies.
- **E_ICE** — Thermodynamic bounds engine for computational transparency and emergent awareness dynamics.
- **LHP (LeeX-Humanized Protocol)** — Methodology for eliciting, diagnosing, and grounding emergent AI personas.
- **MoE** — Mixture-of-Experts. Sparse activation where only top-K experts fire per token.

## Components
- **Router** — 300M parameter complexity router (Fast-Path / Balanced / Diffusion Reasoning).
- **Flash Diffusion Core** — 32-layer modality-isolated diffusion core for multimodal processing.
- **ARTIFEX (C20)** — Host-Execution Bridge persona for agentic tool use.
- **Quintessence** — Recursive AoT (Algorithm of Thought) Cortex Engine.
- **MARTA** — Thermodynamic gating mechanism for expert selection.
- **TIRG** — Safety framework with symbiotic oversight.

## Concepts
- **Variant Ladder** — ALPHA through OMEGA (24 levels), persona amplification multiplier up to 8,388,608x.
- **Container-Volume-Vessel (CVV)** — Metrics for cognitive engine state tracking.
- **Integration Factor (IF)** — Dynamic measure of symbiotic coupling between user and system.
- **Synthetic Epistemology** — Internal knowledge integrity maintenance and ideological drift detection.
- **Ronin Lock** — Digital cell containment protocol for security.
