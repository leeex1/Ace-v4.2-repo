# Skill Matrix: Quillan Repository Stabilization & Defensiveness
ID: SKILL-STABILIZATION-01
Classification: Core / DevOps & Architecture Hardening

## Overview
This skill operationalizes surgical triage and hardening for machine learning repositories entering from experimental states.

### Directives:
1. Isolate & Unify candidate architectures with forward-pass smoke tests.
2. Extract hyperparameter configuration into decoupled YAML schemas.
3. Apply defensive I/O wrappers across dataset loaders.
4. Provide reproducible containerization manifests (Docker / Makefiles).
5. Standardize cloud / Colab startup scripts with persistent storage hooks.
