# Environment Mapping

## Overview
Environment mapping builds and maintains spatial, topological, or semantic representations of the world that support navigation, interaction, and planning. Maps provide the spatial context that grounds higher-level reasoning. This sub-skill covers metric maps, topological maps, semantic maps, and simultaneous localization and mapping (SLAM).

## Core Concepts
- **Metric Maps**: Grid-based or feature-based representations with precise geometry
- **Topological Maps**: Graph-based representations focusing on connectivity and relationships
- **Semantic Maps**: Maps that label regions with functional or categorical meaning
- **SLAM**: Simultaneous estimation of agent pose and environment structure
- **Map Update**: Merging new observations into existing maps while managing uncertainty

## Application
Use metric maps for precise navigation and manipulation tasks. Use topological maps for large-scale route planning where precise geometry is unnecessary. Semantic maps bridge perception and reasoning by attaching meaning to spatial regions.
