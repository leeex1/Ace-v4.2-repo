# Intentionality Detection

## Overview
Intentionality detection is the ability to recognize that actions are caused by underlying intentions and to infer what those intentions are from observable behavior. It involves distinguishing intentional from accidental actions, inferring goals from action sequences, detecting communicative intentions, and recognizing when expressed intentions differ from actual intentions (deception).

## Core Concepts
- **Goal Inference**: Inferring the outcome an agent is trying to achieve based on their actions
- **Plan Recognition**: Identifying the structured sequence of actions an agent intends to execute
- **Intention vs. Accident**: Distinguishing actions performed on purpose from those that are accidental
- **Deception Detection**: Recognizing mismatches between expressed and actual intentions

## Application
Use intentionality detection for cooperative AI, intention recognition in human-robot interaction, deception detection systems, narrative understanding, and any system that must predict future actions based on inferred intentions.
