# Facial Expressions

## Overview
Facial expressions are a primary channel for emotional communication, conveying information about emotional state, cognitive load, social signals, and conversational feedback. The Facial Action Coding System (FACS) provides an anatomically-based framework for describing facial movements through Action Units (AUs). Micro-expressions (sub-200ms) can reveal concealed emotions.

## Core Concepts
- **Universal Expressions**: Happiness, sadness, anger, fear, surprise, disgust (Ekman's six basic emotions)
- **FACS Action Units**: Individual muscle movements that combine to produce all facial expressions
- **Micro-Expressions**: Involuntary, brief (<200ms) expressions that leak concealed emotions
- **Intensity and Asymmetry**: Grading expression intensity; asymmetry may indicate sincerity

## Application
Use facial expression analysis for emotion recognition, affective computing, virtual character animation, deception detection, human-computer interaction, and psychological assessment.
