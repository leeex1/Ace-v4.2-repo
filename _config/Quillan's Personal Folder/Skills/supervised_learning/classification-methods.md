# Classification Methods
## Overview
Classification methods assign input data to predefined categories or classes. This sub-skill covers binary classification, multi-class classification, and multi-label classification approaches including logistic regression, decision trees, support vector machines, and neural networks.
## Core Concepts
- **Logistic Regression**: Probabilistic binary classifier using the logistic function to model class probabilities
- **Decision Boundaries**: Surfaces in feature space that separate different classes
- **Support Vector Machines**: Finding the hyperplane that maximally separates classes with maximum margin
- **Probabilistic Outputs**: Well-calibrated class probabilities versus hard class predictions
## Application
Use classification methods when predicting categorical outcomes such as spam detection, disease diagnosis, image recognition, or customer segmentation.
