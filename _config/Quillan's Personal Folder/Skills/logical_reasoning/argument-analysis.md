# Argument Analysis

## Overview
Argument analysis is the systematic examination of arguments to assess their logical structure, evidential support, and overall strength. This sub-skill covers techniques for identifying premises and conclusions, mapping argument structure, evaluating reasoning, and detecting hidden assumptions.

## Core Concepts
- **Premise-Conclusion Identification**: Distinguishing the claim being argued for (conclusion) from the reasons offered in support (premises). Indicator words (therefore, since, because, hence) provide cues.
- **Argument Structure**: Simple arguments (single premise supporting a conclusion); convergent arguments (multiple independent premises); linked arguments (premises that jointly support the conclusion); serial arguments (chains of reasoning).
- **Enthymemes**: Arguments with unstated premises — identifying and evaluating implicit assumptions is crucial for complete analysis.
- **Evaluation Criteria**: Validity (deductive), strength (inductive/abductive), soundness (validity + true premises), cogency (strength + true premises), and relevance of premises to conclusion.

## Application
Before accepting or challenging an argument, decompose it fully — identify every premise, determine the logical structure, assess each premise's truth, and evaluate whether the premises actually support the conclusion.
