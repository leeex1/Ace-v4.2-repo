# Planning and Task Decomposition

## Overview
A formal framework for decomposing complex goals into structured task hierarchies. This directory contains 7 specialized sub-skills.

## Sub-Skills
1. **[goal-decomposition.md](goal-decomposition.md)** - Breaking high-level goals into manageable sub-goals
2. **[hierarchical-planning.md](hierarchical-planning.md)** - Multi-level abstraction planning
3. **[dependency-mapping.md](dependency-mapping.md)** - Identifying and managing task interdependencies
4. **[resource-planning.md](resource-planning.md)** - Allocating skills, time, budget, and tools
5. **[contingency-planning.md](contingency-planning.md)** - Handling uncertainty and failure scenarios
6. **[temporal-planning.md](temporal-planning.md)** - Scheduling, deadlines, critical paths
7. **[plan-execution.md](plan-execution.md)** - Monitoring and executing plans in real-world conditions
