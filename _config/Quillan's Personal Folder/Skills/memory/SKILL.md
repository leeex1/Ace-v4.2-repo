# Memory

Foundational skill for understanding, designing, and implementing memory systems across human cognitive architecture and artificial intelligence. Covers encoding, storage, retrieval, and forgetting mechanisms with protocols for context window design, vector databases, RAG pipelines, and learning optimization.

## Sub-Skills
1. Encoding Strategies — Techniques for transforming input into storable memory traces
2. Retrieval Techniques — Methods for accessing stored information effectively
3. Working Memory Management — Optimizing limited-capacity cognitive workspace
4. Long-Term Memory Consolidation — Stabilizing memories for durable retention
5. Associative Memory Networks — Building and leveraging relational memory structures
6. Memory Optimization — Maximizing efficiency and capacity of memory systems
7. Forgetting Curve Strategies — Counteracting decay through spaced repetition
