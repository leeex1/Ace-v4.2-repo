# Creative Analogies

## Overview
Creative analogies generate novel insights by connecting domains not previously associated. This sub-skill covers techniques for deliberately generating creative analogies, combining multiple source domains, and using analogy as a tool for innovation and discovery.

## Core Concepts
- **Remote Analogies**: Far-domain analogies (biology to engineering, music to mathematics) produce more creative insights than near-domain analogies. The cognitive distance forces deeper structural abstraction.
- **Analogy by Constraint Relaxation**: Temporarily relaxing constraints on what counts as a valid source domain allows unexpected connections. Refine relevance after exploratory mapping.
- **Blending (Conceptual Integration)**: Combining elements from multiple source domains into a new blended space with emergent properties not present in either input domain.
- **Creative Analogy Heuristics**: What is this problem like? What has solved similar problems? What domain has a similar structure? If this worked there, could it work here? What if the opposite were true?

## Application
Use creative analogies for hypothesis generation, design ideation, and problem reframing. Combine multiple source domains. Test the resulting insights for validity after the creative phase.
