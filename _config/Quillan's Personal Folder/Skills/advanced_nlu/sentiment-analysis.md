# Sentiment Analysis

## Overview
Sentiment analysis determines the emotional tone, attitude, or opinion expressed in text. Beyond simple positive/negative classification, it encompasses fine-grained sentiment intensity, aspect-based sentiment (sentiment toward specific targets), emotion detection (anger, joy, sadness, fear), and stance detection (support/opposition toward a proposition). Idiom and sarcasm present special challenges.

## Core Concepts
- **Polarity Classification**: Positive, negative, neutral with intensity grading
- **Aspect-Based Sentiment**: Identifying sentiment toward specific aspects or features of an entity
- **Emotion Detection**: Classifying discrete emotions (Ekman, Plutchik) or dimensional affect (valence, arousal)
- **Sarcasm and Irony**: Detecting when literal sentiment opposes intended sentiment

## Application
Use sentiment analysis for social media monitoring, customer feedback analysis, brand reputation tracking, market research, and any application requiring automated opinion mining.
