# Audio Production

## Overview
Audio production encompasses the technical and artistic process of capturing, editing, and shaping sound into a finished recording. It bridges performance and listener experience through microphone technique, signal processing, and arrangement decisions. This sub-skill covers recording, editing, DAW workflow, and production philosophy.

## Core Concepts
- **Recording Chain**: Microphone selection, preamp gain staging, and signal path optimization
- **Editing Techniques**: Comping takes, time alignment, pitch correction, and noise reduction
- **DAW Workflow**: Session organization, routing, automation, and template design
- **Gain Staging**: Maintaining optimal signal levels throughout the production chain
- **Production Philosophy**: Serving the song first, using technology to enhance not replace performance

## Application
Start with great source material production cannot fix a bad performance. Organize sessions with consistent naming and color-coding. Use reference tracks to calibrate your sonic goals. Automation is what brings a static mix to life.
