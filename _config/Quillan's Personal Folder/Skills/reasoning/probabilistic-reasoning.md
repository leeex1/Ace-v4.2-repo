# Probabilistic Reasoning

## Overview
Probabilistic reasoning handles uncertainty explicitly using probability theory. This sub-skill covers Bayesian inference, expected utility, stochastic modeling, and decision-making under uncertainty — essential for navigating an uncertain world.

## Core Concepts
- **Bayesian Inference**: Prior beliefs are updated with evidence using Bayes' theorem to produce posterior beliefs. The prior, likelihood, and posterior form a complete belief-updating framework.
- **Expected Utility**: Decisions under uncertainty maximize expected utility — the probability-weighted average of outcomes. Utility functions encode preferences over outcomes.
- **Uncertainty Quantification**: Confidence intervals, credible intervals, prediction intervals, and probability distributions express the degree of certainty (or uncertainty) in estimates and predictions.
- **Common Fallacies**: Base rate neglect, gambler's fallacy, conjunction fallacy, availability heuristic, overconfidence effect — systematic deviations from normative probability reasoning.

## Application
Use Bayesian reasoning to update beliefs as new evidence arrives. Apply expected utility calculations to decisions involving risk. Express forecasts with calibrated confidence intervals rather than point estimates.
