# Accelerated Learning
## Overview
Accelerated learning combines evidence-based techniques to dramatically increase the speed and depth of learning. This sub-skill covers meta-learning strategies, cognitive enhancement techniques, and methods for rapid skill acquisition.
## Core Concepts
- **Meta-Learning**: Learning how to learn effectively by understanding the structure of a domain before diving in
- **Learning How to Learn**: Understanding cognitive principles that can be applied across all learning domains
- **Rapid Skill Acquisition**: Deconstructing skills into core components and practicing the most important elements first
- **Deep Work**: Focused, uninterrupted concentration that maximizes cognitive performance
## Application
Apply accelerated learning techniques when facing tight deadlines for skill acquisition, transitioning to new domains, or maximizing the efficiency of learning time.
