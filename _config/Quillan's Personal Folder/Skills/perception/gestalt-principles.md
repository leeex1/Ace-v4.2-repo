# Gestalt Principles
## Overview
Gestalt principles describe how humans naturally organize visual elements into unified wholes rather than perceiving them as disconnected parts. This sub-skill covers the core principles of perceptual organization including proximity, similarity, closure, continuity, figure-ground, and common fate.
## Core Concepts
- **Proximity**: Elements close together are perceived as belonging together
- **Similarity**: Elements sharing visual characteristics are grouped together
- **Closure**: The mind tends to complete incomplete shapes to form whole objects
- **Figure-Ground**: The automatic separation of visual field into foreground objects and background
- **Continuity**: Lines and patterns are perceived as continuous rather than disjointed
## Application
Apply Gestalt principles when designing user interfaces, data visualizations, logos, and any visual communication that requires rapid and intuitive comprehension.
