# Model Evaluation
## Overview
Model evaluation involves assessing how well a trained model generalizes to unseen data. This sub-skill covers evaluation metrics, cross-validation strategies, bias-variance diagnosis, and statistical comparison of model performance.
## Core Concepts
- **Cross-Validation**: K-fold, stratified, and leave-one-out methods for robust performance estimation
- **Performance Metrics**: Accuracy, precision, recall, F1, ROC-AUC for classification; MSE, MAE, R-squared for regression
- **Bias-Variance Tradeoff**: Diagnosing whether a model underfits or overfits the training data
- **Learning Curves**: Plotting performance against training set size to diagnose learning behavior
## Application
Apply model evaluation techniques when selecting between competing models, tuning hyperparameters, or estimating real-world performance before deployment.
