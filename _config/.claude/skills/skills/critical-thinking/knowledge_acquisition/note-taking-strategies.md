# Note Taking Strategies
## Overview
Effective note taking is essential for capturing, organizing, and retaining information from various sources. This sub-skill covers structured note-taking methods, digital tools, and systems for personal knowledge management.
## Core Concepts
- **Cornell Method**: Dividing notes into cues, notes, and summary sections for efficient review
- **Zettelkasten**: Building a system of interconnected atomic notes for idea development
- **Mind Mapping**: Visual organization of concepts around central themes using branching structures
- **Progressive Summarization**: Layered summarization from raw capture through refined highlights
## Application
Use note-taking strategies when learning new subjects, conducting research, attending lectures or meetings, and building personal knowledge management systems.
