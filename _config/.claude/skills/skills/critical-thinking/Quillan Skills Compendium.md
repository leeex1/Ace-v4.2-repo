# Quillan Skills Compendium

## Overview

Master runtime protocol and configuration manifest for all Quillan operational skills. This compendium maintains the canonical registry organized by domain category with complete metadata for each skill including power tier, council assignment, activation phrases, protocols, and default outputs. Use this as the primary reference for navigating and understanding the complete Quillan skill ecosystem.

## Core Principles

- **Single Source of Truth:** This compendium is the authoritative reference for the entire skill ecosystem — every skill's metadata, council assignment, and activation pattern.
- **Category-Driven Organization:** Skills are grouped by domain category (Research & Analysis, Creative & Innovation, Technical & Coding, etc.) to enable rapid discovery and cross-reference.
- **Complete Schema Per Entry:** Every skill entry includes all metadata fields needed for both human navigation and automated processing.

## How to Use This Compendium

1. **Find a skill:** Browse categories or search for the task domain
2. **Read the entry:** Check power tier, council members, activation phrases, and protocol
3. **Activate:** Use the activation phrase to trigger the skill in conversation
4. **Cross-reference:** Note council assignments for multi-skill coordination
