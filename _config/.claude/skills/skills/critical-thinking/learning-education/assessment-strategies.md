# Assessment Strategies
## Overview
Assessment strategies encompass methods for measuring student learning, providing feedback, and evaluating educational effectiveness. This sub-skill covers formative versus summative assessment, authentic assessment, rubric design, and feedback practices.
## Core Concepts
- **Formative Assessment**: Ongoing assessment during learning to provide feedback and guide instruction
- **Summative Assessment**: End-of-unit evaluation of cumulative learning against standards
- **Rubric Design**: Criteria-based scoring guides that make expectations explicit
- **Authentic Assessment**: Evaluation through real-world tasks that demonstrate meaningful application
## Application
Apply assessment strategies when designing courses, evaluating learning outcomes, providing feedback, or measuring educational program effectiveness.
