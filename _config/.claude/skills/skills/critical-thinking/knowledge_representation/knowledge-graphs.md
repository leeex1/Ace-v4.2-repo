# Knowledge Graphs

## Overview
Knowledge graphs (KGs) are large-scale knowledge bases that use graph-structured data models to integrate information from heterogeneous sources while preserving semantics. They represent entities as nodes and relations as edges, often enriched with attributes, named graphs, and provenance metadata. KGs power semantic search, recommendation systems, question answering, and AI reasoning pipelines.

## Core Concepts
- **Entity- Relation Model**: Nodes represent real-world entities; edges represent relationships with typed labels
- **Triple Stores**: RDF-based storage using subject-predicate-object triples queried via SPARQL
- **Property Graphs**: Graph databases (Neo4j) with nodes and relationships that can hold properties
- **KG Construction**: NER/NEL, relation extraction, entity resolution, schema mapping, embedding

## Application
Use knowledge graphs when integrating data from multiple sources, enabling semantic search, supporting recommendation systems, or building AI reasoning pipelines that require structured world knowledge.
