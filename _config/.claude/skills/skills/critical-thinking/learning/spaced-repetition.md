# Spaced Repetition
## Overview
Spaced repetition is a learning technique that involves reviewing information at increasing intervals over time to maximize long-term retention. This sub-skill covers the spacing effect, optimal scheduling algorithms, and practical implementation strategies.
## Core Concepts
- **Spacing Effect**: Information is better remembered when study sessions are distributed over time rather than massed
- **Forgetting Curve**: The exponential decline of memory retention over time without review
- **Optimal Interval**: The ideal time to review information is just before it would be forgotten
- **Leitner System**: A simple spaced repetition implementation using physical flashcards sorted by review frequency
## Application
Use spaced repetition when studying for exams, learning vocabulary, mastering factual knowledge, or designing any system where long-term retention is critical.
