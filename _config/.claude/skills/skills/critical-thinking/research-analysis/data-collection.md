# Data Collection

## Overview
Data collection gathers information from multiple sources to support analysis and answer research questions. The quality of any analysis is fundamentally limited by the quality of the data feeding it. This sub-skill covers primary and secondary data collection methods, sampling strategies, and data quality assurance.

## Core Concepts
- **Primary Data Collection**: Surveys, interviews, experiments, and observations designed for the specific research question
- **Secondary Data Sources**: Existing datasets, archives, public records, and published literature
- **Sampling Strategies**: Random, stratified, convenience, and purposive sampling with bias awareness
- **Data Quality Dimensions**: Accuracy, completeness, consistency, timeliness, and validity
- **Data Management**: Storage, organization, documentation, and ethical handling of collected data

## Application
Match data collection method to the research question and resources available. Document all collection procedures for reproducibility. Validate data quality before analysis. For sensitive data, ensure ethical approval and informed consent.
