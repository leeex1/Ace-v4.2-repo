# Causal Reasoning

The capacity to identify, model, and test cause-effect relationships in complex systems. Unlike mere correlation, causality establishes directional influence and enables counterfactual reasoning. Provides frameworks for causal inference, experimental design, counterfactual analysis, and mechanistic explanation.

## Sub-Skills
1. Causal Inference — Drawing causal conclusions from data and assumptions
2. Counterfactual Thinking — Reasoning about alternative scenarios
3. Intervention Analysis — Predicting effects of deliberate actions
4. Causal Graphs — Representing causal assumptions with DAGs
5. Correlation vs. Causation — Distinguishing association from causal relationships
6. Causal Discovery — Learning causal structures from data
7. Mechanism Explanation — Explaining the how of causal relationships
