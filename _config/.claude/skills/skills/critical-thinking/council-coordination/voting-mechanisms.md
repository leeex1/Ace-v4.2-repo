# Voting Mechanisms

## Overview
Voting mechanisms provide formal methods for aggregating council member preferences into collective decisions. When natural consensus cannot be reached, voting provides a clear, traceable path to resolution. This sub-skill covers simple majorities, confidence-weighted voting, ranked choice, and tie-breaking procedures.

## Core Concepts
- **Simple Majority**: Each member votes AYE/NAY/ABSTAIN with majority deciding
- **Confidence-Weighted Voting**: Members vote on a 0.0-1.0 scale weighted by domain relevance
- **Ranked Choice**: Members rank options to reveal preference intensity and compromise positions
- **Quorum Requirements**: Minimum participation needed for a valid vote
- **Tie-Breaking**: C17-NULLION and C31-NEXUS resolve tied votes through arbitration

## Application
Use simple majority for low-stakes procedural decisions. Use confidence-weighted voting for nuanced strategic choices where support strength matters. C2-VIR has veto power on any outcome violating ethics gate.
