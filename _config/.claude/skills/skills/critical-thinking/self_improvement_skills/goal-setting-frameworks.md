# Goal Setting Frameworks

## Overview
Goal setting frameworks provide structured approaches for defining improvement targets. This sub-skill draws on C12-SOPHIAE's wisdom and C5-ECHO's experience to establish goals that are ambitious yet achievable, specific yet adaptable.

## Core Concepts
- **SMART Criteria**: Specific (clear target), Measurable (quantified outcome), Achievable (within capability), Relevant (aligned with values), Time-bound (with deadline). Extends to SMARTER with Evaluate and Re-evaluate.
- **Proximal vs Distal Goals**: Proximal goals (immediate next steps) provide motivation and clear feedback; distal goals (long-term targets) provide direction. Effective improvement frameworks maintain both.
- **Learning Goals vs Performance Goals**: Learning goals focus on acquiring new capability; performance goals focus on demonstrating existing capability. Improvement requires more learning goals; deployment requires more performance goals.

## Application
Use goal setting frameworks when designing improvement plans by: (1) articulating the desired capability in SMART terms, (2) identifying the prerequisite knowledge/skills, (3) setting proximal milestones that lead to the distal goal, (4) balancing learning and performance goals according to the improvement phase.
