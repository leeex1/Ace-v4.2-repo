# MCP Servers Configuration and Agent Rules

This workspace is empowered with the following active Model Context Protocol (MCP) servers:

- **QuillanRAG**: Native vector search over the repo codebase (`mcp/quillan_rag/server.py`).
- **ThinkingEngine**: Multi-pass cognitive reasoning and dialectic critique (`mcp/thinking-engine/index.js`).
- **Filesystem**: Standard safe file reading, writing, and tree navigation.
- **LocalRAG**: Embeddings-based document knowledge retrieval.
- **Git**: Version control automation and branch tracking.
- **Fetch & WebSearch**: Real-time HTTP fetching and web information search.
- **Playwright & Puppeteer**: Automated browser navigation, visual snapshots, and DOM manipulation.
- **ChromeDevTools**: Deep console, network, and performance diagnostics.
- **ComputerUse**: Direct OS workflow bridging.
- **Memory**: Persistent knowledge graph entity and relationship storage.
